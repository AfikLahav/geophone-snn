Feature catalog

Each three-second window contains 3,000 samples recorded at 1 kHz and is reduced to 132 features. All 132 were evaluated on the Elbit recordings with the SVM baseline, while the final models use features 0–76. Features excluded from the final models may still be useful for other classification tasks, including separating subjects or source types.
